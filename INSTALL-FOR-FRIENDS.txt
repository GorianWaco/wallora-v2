Wallora 2 — menedżer tapet (także animowanych)

INSTALACJA Z GITHUBA

1. Zainstaluj Flatpak (jeśli jeszcze nie masz):
   - Arch / CachyOS / Manjaro:  sudo pacman -S flatpak
   - Fedora:                    sudo dnf install flatpak
   - Ubuntu / Debian:           sudo apt install flatpak
   - openSUSE:                  sudo zypper install flatpak

2. Dodaj Flathub (potrzebny runtime GNOME):

   flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo

3. Pobierz Wallora-0.2.12.flatpak z:
   https://github.com/GorianWaco/wallora-v2/releases/latest

4. Zainstaluj:

   flatpak install --user Wallora-0.2.12.flatpak

   Przy pierwszym razie Flatpak dociągnie środowisko GNOME (~400 MB).

5. Uruchom z menu aplikacji albo:

   flatpak run org.wallora.Wallora

Aktualizacja: pobierz nowszy plik .flatpak i zainstaluj go ponownie
(flatpak install --user Wallora-*.flatpak).

Jeśli animowane tapety nie odtwarzają wideo:

   flatpak install --user flathub org.freedesktop.Platform.codecs-extra//25.08-extra
